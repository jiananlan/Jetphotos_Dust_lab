快速使用说明
1. 导入 JPEG，自动显示左侧正常照片和右侧实时 Dust。 2. 调整强度与检测半径，让天空灰尘显形。 3. 在任意一侧 Alt + 左键或右键取样，再左键涂抹。 4. 两侧同步修复、缩放和平移；[ / ] 调笔刷，Ctrl+Z 撤销。 触控板：双指上下左右滑动平移，捏合或 Ctrl+双指滑动缩放。 鼠标：滚轮上下平移，Shift+滚轮横移，Ctrl+滚轮缩放。 5. 检查左侧正常照片后保存；按 C 可切换单视图。 Dust 调色只参与预览；输出始终使用正常色彩的修复像素。

检查与修复

原色与 Dust 实时对照；两侧同步取样、涂抹、缩放和平移。

放心输出

Dust View Setting 只影响预览。导出使用原色修复结果，保留并校验 EXIF、XMP、ICC 和 IPTC。

支持 JPG / JPEG / JPE。输出为 JPEG 质量 100、4:4:4；JPEG 仍属于有损编码。
